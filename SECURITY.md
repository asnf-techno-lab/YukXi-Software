## Filosofi "AnXin"

Sesuai dengan nama proyek kami, "AnXin (安心)" yang berarti "Ketenangan Pikiran", Shinko Engine dirancang untuk mengunduh installer hanya dari sumber resmi (Official Vendor Servers). Kami tidak pernah menyimpan file installer pihak ketiga di server kami untuk menghindari risiko malware injection.
